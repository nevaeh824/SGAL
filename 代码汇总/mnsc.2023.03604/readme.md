## REPLICATION GUIDE ##

The implementation of the methods described in our paper is primarily carried out in four main steps.

**1. News Collection**

`news\fraud_news_collect.py` is designed to automatically collect the news regarding financial statement fraud for each Chinese listed company from the website [http://www.bjinfobank.com/DataList.do?method=DataList](http://www.bjinfobank.com/DataList.do?method=DataList). It should be noted that access to the news content on this website is not free of charge. You are required to purchase the service using your account. There could potentially be legal issues when crawling websites. Please contact the website manager in advance before using this code.

`news\total_news_count_obtain.py` helps to quickly obtain the total number of all news related to a certain company. The obtained number of news is used to calculate the FSFP measurement index. This code runs much faster than `news\fraud_news_collect.py` because it does not need to collect specific news report content.

`news\stockname_history.csv` encompasses the historical names of all Chinese stocks, as companies may alter their listed names within the sample period. This file is sourced from the CSMAR database.

`news\collecting_check.csv` serves to record the extent to which firms have completed news collection and the number of firms that have not yet done so. This is necessary because the collecting process may be interrupted by factors such as network connectivity issues and website traffic throttling.

All collected news articles related to financial fraud are stored in the `news\data` folder, with each stock having its own separate file. However, due to legal concerns, we do not include the collected news data here. Readers are responsible for obtaining the complete set of news data independently.


**2. Measure Construction**

`FSFP_calc.py` is designed to calculate the FSFP measures, utilizing the news data that has been collected.

`FSFP_plot.py` is used to generate Figure 1 in the paper. The input file `data\FSFP.csv` is produced by running the script `FSFP_calc.py`.

`terms\finwords.txt`: Words showed in this file is used to determing whether FS-related terms and fraud-related terms are appeared in the same paragraph.
 
`terms\fraudwords.txt`: Words showed in this file is used to calculate the frequency of fraud words.

`terms\stopwords.txt`: A list of common Chinese stop words.

`terms\stocknames.txt`: It includes the stock names of Chinese listed companies. 


**3. Peer Identification**

`bus_sim_calc.py` is designed to calcalting the business similarity among firms. The input file `data\firm_bus_text.csv` is downloaded from EastMoney ([https://www.eastmoney.com](https://www.eastmoney.com)), storing the text part of "Business Summary" in the annual financial reports of Chinese listed companies. The calculated business similarity will be stored in the folder `output\bus_sim`.

`peer_identify.py` is used for peer/community identification within the business similarity network and for generating Figure 2 of the paper. The generated figures will be saved in the `output\` folder. Additionally, the identified Peer IDs for each firm in each year are saved in `output\peer_identified.csv`.


**4. Fraud Prediction**

`factors_gen.py` is utilized to generate input variables for the detection model, including feature sets and labels. All variables are defined in Tables 8 and 9 of the paper. Notably, the data stored in `data\CSMAR_data` must be downloaded from the CSMAR database ([https://data.csmar.com](https://data.csmar.com)), and the data in `data\Datago_data` must be obtained from the Datago database ([https://datago.com](https://datago.com)). The input variables generated by running this script are saved in `data\model_input.csv`.

`detection_model.py` is designed to produce fraud detection results based on the input variables provided. Specifically, the prediction outcomes for each firm in every year will be stored in `output\`.


## OTHER MATERIALS ##

Other materials that support the arguments are stored in the folder `others\`.

`performance_heatmap.py`: It illustrates the performance changes based on the prediction results. Running this script will generate Figure 4.

`eco_value_calc.py`: It facilitates the calculation of the economic values of the detection model, as demonstrated in Table 12.

`FSFP_threshold.py`: It will plot Figure 5 based on the prediction results.

`figureA1.xlsx`: It plots Figure A1 based on the data`\audit_fee_mean.csv` generated by running the function `audit_fee_calc()` in `eco_value_calc.py`.
